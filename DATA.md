# Data Access and Release Boundary

## CareerBuilder

The CareerBuilder Job Recommendation Engine Challenge files originated from the competition data page at <https://www.kaggle.com/competitions/job-recommendation/data>. Original and processed records describing individual coded users, jobs, work histories, or applications are not redistributed in this repository. Source-level reproduction requires independently authorized access under the applicable provider terms.

The repository contains CareerBuilder analysis code, protocol descriptions, non-row-level aggregate results, selected path-free integrity summaries, and aggregate SVG figures. These materials do not replace the provider data.

## JTH

JTH v1.1 is available from <https://zenodo.org/records/21390581>, with code and documentation at <https://github.com/Aunsiels/JTH>. The released dataset is governed by the Creative Commons Attribution-NonCommercial 4.0 International license and associated conditions. Obtain JTH from its official source and follow its documentation, non-commercial restriction, and safeguards against re-identification.

JTH-derived aggregate tables and figures in this repository are marked as modified/derived research outputs and remain subject to the relevant upstream conditions; see [RIGHTS.md](RIGHTS.md).

## Excluded materials

The public release excludes:

- original or processed provider records;
- individual coded records and individual-level outputs;
- per-user and per-query evaluation files;
- cached embeddings derived from restricted inputs;
- model caches and checkpoints;
- query-selection files containing user identifiers;
- exact timestamp definitions withheld after disclosure-risk review; and
- local-path execution logs.

Unobserved candidate–query pairs are treated as non-relevant only for the declared logged evaluation. The released aggregates should not be interpreted as evidence about worker quality, suitability, welfare, or latent preference validity.
